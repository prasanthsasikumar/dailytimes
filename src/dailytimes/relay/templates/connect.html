1. Add it to your assistant

Claude claude.ai, the desktop app and the phone app

  1. Open Settings → Connectors on claude.ai (or in the desktop app).
  2. Click Add custom connector. Name it Daily Times, paste your connector link as the URL, leave the advanced settings empty, and click Add.
  3. Start a new chat. In the + menu, check that Daily Times is switched on (and your calendar and Gmail, if you use them).
  4. Paste the prompt from step 2 into that chat.

Pasting the link into a chat won't connect anything: Claude can only use Daily Times once it's added in Settings. After that it works on the web, desktop and phone.

ChatGPT

  1. Open Settings → Apps & Connectors → Advanced settings and turn on Developer mode. ChatGPT only offers this on paid plans.
  2. Back in Apps & Connectors, click Create. Name it Daily Times, paste your connector link as the MCP server URL, choose No authentication, tick that you trust it, and click Create.
  3. Start a new chat, open the + menu, choose Developer mode and switch on Daily Times.
  4. Paste the prompt from step 2 into that chat.

Gemini

If your Gemini app has no option to add a custom (MCP) connector, it can't send us an edition. Two ways around that:

  1. Gemini CLI takes connectors. In a terminal, run: 
    gemini mcp add --scope user --transport http dailytimes "{{ url }}"
    Then start gemini again, check /mcp lists dailytimes, and paste the prompt from step 2.
  2. Or skip the AI: tell us what you're into and we'll build an edition every morning from public news.

Claude Code

  1. In a terminal (not inside a Claude Code chat), run: 
    claude mcp add --scope user --transport http dailytimes "{{ url }}"

    --scope user makes it work in every folder. Without it, Claude Code only loads it in the folder you ran the command in.

  2. Quit Claude Code and start it again: it loads connectors at startup. Type /mcp and check dailytimes shows as connected.
  3. Paste the prompt from step 2.

Claude Code only runs while it's open. For an edition that's ready when you wake up, add the link to Claude on claude.ai as well.

Codex

  1. In a terminal, run: 
    codex mcp add dailytimes --url "{{ url }}"

    Or add this to ~/.codex/config.toml:

    [mcp_servers.dailytimes]
url = "{{ url }}"
  2. Start Codex again and check /mcp lists dailytimes.
  3. Paste the prompt from step 2.
